## Summary

The definitive clinical manual for EMDR therapy. Shapiro presents the Adaptive Information Processing (AIP) model as the theoretical framework for EMDR, along with detailed 8-phase treatment protocols. The book covers client selection, preparation, assessment, desensitization, installation, body scan, closure, and reevaluation phases. It includes verbatim transcripts demonstrating each phase of treatment.

## Key Content

- **8-phase EMDR protocol:** The standardized clinical procedure for EMDR therapy, including bilateral stimulation parameters
- **Bilateral stimulation rate:** Shapiro specifies alternating bilateral stimulation (eye movements, taps, or tones) at approximately 1 set per second (1 Hz), with sets of 24-36 passes
- **Adaptive Information Processing model:** Traumatic memories are stored in state-specific, maladaptive neural networks. EMDR facilitates the connection of these networks with adaptive information networks
- **Dual attention:** The client simultaneously attends to the traumatic memory AND the bilateral stimulus, creating a dual-attention condition that is theorized to facilitate information processing
- **Clinical populations:** PTSD, phobias, grief, anxiety, sexual abuse survivors, combat veterans

## Relevance to Aureonoise

This is the clinical reference for EMDR bilateral stimulation parameters. Shapiro's specification of ~1 Hz bilateral alternation rate, combined with Rousseau 2020's fMRI validation of 1.0-1.3 Hz (paper 010), establishes the evidence base for Aureonoise's BilateralOscillator rate. The AIP model's emphasis on dual-attention (simultaneous memory activation + bilateral task) informs how Aureonoise should be used: as a bilateral dual-attention stimulus during emotional processing, not as a passive listening experience.
