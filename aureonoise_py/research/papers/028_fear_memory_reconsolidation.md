# 028 — Fear Memories Require Protein Synthesis for Reconsolidation (Nader et al. 2000)

## Metadata
- **Title:** Fear memories require protein synthesis in the amygdala for reconsolidation after retrieval
- **Authors:** Karim Nader, Glenn E Schafe, Joseph E Le Doux
- **Year:** 2000
- **Journal:** Nature
- **DOI:** 10.1038/35021052
- **PubMed:** 10963596
- **URL:** https://www.nature.com/articles/35021052

## Abstract
The study demonstrates that consolidated fear memories, when reactivated, become temporarily unstable and require new protein synthesis in the amygdala for reconsolidation. Researchers used anisomycin (a protein synthesis inhibitor) infused into the lateral and basal amygdala nuclei. Consolidated fear memories, when reactivated during retrieval, return to a labile state in which infusion of anisomycin shortly after memory reactivation produces amnesia. The effect was time-limited — delaying infusion six hours post-reactivation prevented amnesia. Without memory reactivation, anisomycin had no effect on established memories.

## Key Findings
- Consolidated memories become labile upon reactivation (retrieval opens a reconsolidation window)
- Protein synthesis inhibition during this window produces amnesia for the reactivated memory
- The reconsolidation window is time-limited (~6 hours)
- Without reactivation, established memories are stable and resistant to disruption

## Relevance to Aureonoise
This is THE foundational paper for memory reconsolidation. The reconsolidation window is the therapeutic target: when a traumatic memory is reactivated, it becomes temporarily labile and can be modified. Aureonoise's bilateral stimulation during this window (as in EMDR) could facilitate adaptive reconsolidation — the memory is re-stored with reduced emotional charge. The time-limited nature (~6 hours) defines the therapeutic session window. This connects directly to EMDR papers (010-014).
